## Architecture & Principles

- **Privacy by Architecture**: Zero backend database for user journal inputs, quiz answers, or personal notes — everything computes inside the visitor's browser.
- **12-Language Native Localization**: English, Korean, Japanese, German, French, Spanish, Portuguese, Chinese, Hindi, Indonesian, Turkish, and Russian.
- **Mobile-First Accessibility**: Verified across 390×844 viewports with 0px horizontal overflow, >=44px touch targets, and WCAG-friendly contrast.
